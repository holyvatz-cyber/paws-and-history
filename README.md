# 🐾 Paws & History

A responsive, English-language calendar celebrating real milestones in canine history, widely observed dog-related days, and imagined dog holidays.

## Features
- Mobile-friendly editorial design
- Month navigation, category filters and search
- Single-event .ics download for Apple Calendar, Outlook and other compatible calendars
- Annual recurring .ics export for the entire calendar
- Google Calendar event links and event sharing
- Pure HTML, CSS and JavaScript. No build process or backend required.

## GitHub Pages
Open **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**. The site will appear at https://holyvatz-cyber.github.io/paws-and-history/ after deployment.

## Notes
Dates are categorized as History, Observance, or Playful. Many observances are informal, regional or not official holidays. Historical descriptions are short summaries, not exhaustive scholarly references. Calendar exports are yearly recurring all-day events. Importing the complete calendar more than once may create duplicates.

## 🎄 Vánoční trhy
Samostatná mapová aplikace ve složce [`vanocni-trhy/`](vanocni-trhy/index.html) (po nasazení na https://holyvatz-cyber.github.io/paws-and-history/vanocni-trhy/).
- Mapa Česka a sousedních zemí (DE, AT, SK, PL) s ~70 vánočními trhy
- Výchozí bod je vaše poloha, trhy se řadí podle vzdálenosti
- Tlačítkem ✏️ „Oblast“ nakreslete prstem na mapě oblast a zobrazí se trhy v ní
- Detail trhu: termín, otevírací doba, popis, navigace a vyhledání dalších informací
- Termíny pro sezónu 2026/27 jsou orientační, ověřte je u pořadatele
